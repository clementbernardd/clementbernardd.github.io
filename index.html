BIOINFORMATICS · 2025

RNA-TorsionBERT

A language model that predicts RNA torsion angles from the sequence alone.

GitHub ↗ Paper ↗

Predicting 3D coordinates directly is hard. Instead, RNA-TorsionBERT predicts the angles that describe how each nucleotide's backbone twists. It's a BERT-based language model (DNABERT, ~87M parameters) trained on about 4,200 RNA structures. On RNA-Puzzles and CASP-RNA, it improves the MCQ (mean of circular quantities) over SPOT-RNA-1D and over angles inferred from existing methods.

It also comes with TB-MCQ, a scoring function that judges a predicted 3D structure by comparing its angles with the ones RNA-TorsionBERT predicts.

The angles it predicts
α β γ δ ε ζ
Six backbone torsions, each defined by four consecutive atoms along P – O5′ – C5′ – C4′ – C3′ – O3′ – P.
χ
The glycosidic torsion: how the base is oriented relative to the sugar.
ν₀ – ν₄
Five sugar-ring torsions that describe the ribose pucker.
η θ
Pseudo-torsions on a coarse-grained P and C4′ trace, a compact summary of the backbone.

Angles are periodic, so the model predicts the sine and cosine of each one and converts them back to degrees.

Rebuild an RNA from its angles

If you keep every bond length and bond angle constant, the torsion angles alone determine the 3D shape. Below, the backbone is rebuilt atom by atom from its torsions (the NeRF algorithm), using average bond lengths and angles. The grey trace is the reference structure. Has AlphaFold 3 achieved success for RNA?

A benchmark of AlphaFold 3 on RNA 3D structure prediction.

GitHub ↗ Paper ↗

AlphaFold 2 transformed protein structure prediction. AlphaFold 3 extends it to RNA, DNA, ligands and ions. We compared it with ab initio, template-based and deep learning methods on five test sets, including orphan RNAs and long RNAs.

Predictions were scored with a wide panel of metrics computed with RNAdvisor. We also looked at key RNA interactions: Watson-Crick and non-Watson-Crick base pairs, and stacking.

State-of-the-RNArt

Benchmarking current methods for RNA 3D structure prediction.

GitHub ↗ Paper ↗

An open benchmark of RNA 3D structure prediction tools on three test sets: RNA-Puzzles, CASP-RNA and RNASolo. It has since been updated to include AlphaFold 3, alongside 10 other methods.

PHD THESIS · CHAPTER 6

From sequence to 3D structure with frames

A language-model-based network that predicts one rigid frame per nucleotide, AlphaFold 2 style, then rebuilds every atom.

Following AlphaFold 2, each nucleotide i gets a rigid frame Fi = (Ri, ti): a rotation Ri ∈ SO(3) and a translation ti. A canonical nucleotide written in local coordinates is placed with xglobal = Ri xlocal + ti. Every nucleotide is rebuilt independently and in parallel, so errors don't pile up along the chain the way they do with torsion angles, and multi-stranded RNAs are handled naturally.

The frame gives a coarse-grained model (3–4 atoms per nucleotide), which Arena then turns into a full-atom structure. Before training anything, I measured how much each representation loses by rebuilding structures from their true values. With the NuFold frame, frames were the most accurate modality.

The model
RNAEmbedder
A language model (RiNALMo, RNAErnie, RNABERT or DNABERT) embeds the sequence and builds a pair representation, replacing the MSA used by AlphaFold.
Pairformer
Triangle attention between the pair and sequence representations (from Boltz-1).
Structure Module
Starts from a black-hole initialisation and uses Invariant Point Attention, with recycling, to predict Ri, ti and a pLDDT confidence per nucleotide.
Loss
FAPE − 0.1·FAPEblack-hole + 0.2·Ldist + 0.1·Langles + 0.01·LpLDDT

Simplified demo on the tRNA (PDB 1EHZ). The frames come from the crystal structure rather than from the model. The all-atom step places a rigid, averaged nucleotide on each frame instead of running Arena, so the ranking of representations here differs from the thesis. The pLDDT head learns to predict lDDT; here the true per-nucleotide lDDT (on C4′) is shown instead. Rotation errors barely move the frame origins, so TM-score stays high while base pairs break and INF drops. Translation errors hurt every metric.

Which representation loses the least?

Structures rebuilt from the true values of each modality, then converted to all-atom with Arena, on RNA-Puzzles, CASP-RNA and RNASolo (thesis Table 6.2, mean ± s.d.).

Frames give the best RMSD, INF, TM-score and clash score. Torsion angles (with true bond angles) keep local geometry better (MCQ) but struggle with multi-stranded RNAs. Among frame representations, NuFold (O4′, C1′, C2′, N) scored best, followed by Custom reduced, though the differences were not significant.

STATUS

Work in progress. Trained on 1,005 structures (RNASolo + RNA3DB split) and 15,198 filtered synthetic structures (RFdiffusion, ranked with N-META), the model overfits a single structure but does not yet generalise: validation TM-scores stayed below 0.2 and predictions tend towards helix-like shapes. The reconstruction study above holds independently of this, and the model remains a sequence-only, MSA-free starting point.

M2 PROJECT · GENIOMHE

Coarse-grained RMSD vs. common metrics

A project I designed for master's students. Starting from 22 non-redundant RNA-Puzzles structures and predictions from several models, students build a coarse-grained RMSD and compare it with RMSD, MCQ and TM-score. The repository provides the data, precomputed scores and helper code for superimposing point sets.
